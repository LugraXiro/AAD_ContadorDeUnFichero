# Counting Words and Lines in a File (Java)

This Java project counts how many **words** and **lines** a text file contains.

It uses the **File** and **Scanner** classes to read the file and go through its contents.

- One method counts the words (`numPalabras`), reading them one by one.  
- Another method counts the lines (`numLineas`), reading line by line.

The result is displayed in the console, showing the total number of words and lines in the file.

This project is a simple exercise to practice file handling and the use of the `Scanner` class in Java.
